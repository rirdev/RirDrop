# RirDrop

Offline Local File Sharing & Media Streaming Suite.

- **Offline High-Speed Transfer**: Transfer large files and folders across PCs and mobile devices over local Wi-Fi with 0 internet data.
- **Instant Media Streaming**: Stream video and audio directly without waiting for complete downloads (HTTP 206 Partial Content).
- **Web Client Portal**: Any phone, tablet, or laptop can connect instantly via QR code without installing extra software.
- **Cross-Platform**: Support for Linux, Windows, and mobile devices.
- **Built-in Update & Release System**: Integrated notification manager and web admin panel for broadcasting updates.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/rirdev/RirDrop.git
cd RirDrop

# Install dependencies
npm install

# Start the application
npm start
```

## Running Tests

```bash
npm test
```
